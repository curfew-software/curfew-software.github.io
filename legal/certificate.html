Local certificate disclosure — Curfew for Windows

A transparent explanation of the local certificate Curfew uses. This exists for user trust, for antivirus/store reviewers, and as the in-app consent text.

What it is

To show a proper "This site is blocked" page on HTTPS websites (instead of a raw browser connection error), Curfew runs a tiny web server on your own computer at 127.0.0.1 and needs a certificate browsers will trust for the blocked site. To do that it:

  1. Generates a local root certificate authority (CA) named "Curfew Local Block CA" on your PC.
  2. Adds that CA to your machine's Trusted Root store so the block page loads without a warning.
  3. Uses it to issue on-the-fly certificates only for sites you have chosen to block, served

only from 127.0.0.1.

What it is not

  • It is not a man-in-the-middle proxy. Curfew does not sit between you and the internet, and does

not decrypt, inspect, log, or modify your real web traffic.

  • The certificate is used only to render Curfew's own block page for domains you blocked.

How the key is protected

  • The CA's private key is generated on your machine and never leaves it.
  • It is stored DPAPI-encrypted (Windows machine scope) in a directory whose permissions are

restricted to Administrators and SYSTEM — so other user accounts on the PC cannot read it.

It's optional, and you are asked first

Curfew asks before it installs anything. On first run it shows this explanation and waits for an explicit yes; nothing is added to your trust store unless you agree. Declining — or simply closing the prompt — is treated as "no."

Without the certificate, blocked HTTPS sites fail to connect instead of showing the friendly block page. Blocking is exactly as strict either way, because the block itself comes from the hosts-file redirect, not from the certificate.

Changing your mind

Right-click the Curfew tray icon → "Block page certificate…" to install or remove it at any time. Removing it takes the CA out of the machine trust store and deletes the stored key immediately — you do not have to uninstall Curfew to get rid of it.

Removal

Uninstalling Curfew removes the CA from your trust store and deletes its key, and undoes the hosts and DNS changes. You can also remove "Curfew Local Block CA" manually via certmgr.msc → Trusted Root Certification Authorities.
